# AGENTS.md — правила для всех ИИ-агентов в этом репозитории

Читается агентом каждого участника перед любой работой.
Claude Code читает `CLAUDE.md` — это его копия, держите их одинаковыми.

## Контекст
ХимБио-хакатон «Синтез», ИТМО. Кейс 1 от ПИШ ИТМО. Защита 13.11.
Прототип мультиагентной системы на LLM для автоматизации drug discovery & design.

Главное требование заказчика, по которому нас оценивают:
**система обязана прозрачно различать реальные расчёты, ML-предсказания и гипотезы.
Вымышленных результатов быть не должно.**

Это не пожелание к стилю. Это критерий оценки и единственное, чем мы
отличаемся от остальных команд, взявших тот же кейс.

## Жёсткие запреты

1. **НИКОГДА не возвращай числовое значение без заполненных `provenance` и `source`.**
   Нечего взять — верни `schemas.not_computed(name, reason)`. Явный пропуск лучше тихого нуля.
2. **НИКОГДА не придумывай SMILES, ΔG, IC50, pIC50, ID записей в базах.**
   Любое такое значение приходит из вызова инструмента или не приходит вообще.
   Правдоподобная догадка уедет в демо и всплывёт на вопросе жюри.
3. **НИКОГДА не редактируй файл вне своей зоны ответственности**
   без явного согласования. Нужна правка в чужом — скажи человеку.
4. **НИКОГДА не меняй `src/schemas.py`.** Он заморожен с 20:20 среды.
   Это контракт между всеми слоями, каждая правка ломает работу троих.
5. **НИКОГДА не добавляй зависимость в `requirements.txt` без явной просьбы.**
   Новый пакет — риск сломать окружение всей команде.
6. **НИКОГДА не глуши ошибку пустым `except`.** Тихий except на хакатоне —
   это полчаса поиска причины в три часа ночи.

## Обязательно

- Перед правкой перечисли файлы, которые тронешь, и дождись подтверждения.
- Все внешние вызовы — **только** через `@cached` из `src/cache.py`.
  Прямой запрос в сеть ломает офлайн-демо на защите.
- Функции инструментов возвращают `list[Value]` или `Value` (см. `src/schemas.py`).
- Код должен работать при `OFFLINE=1`, беря данные из `cache/`.
- Если задача требует тронуть больше трёх файлов — остановись и предложи разбить.
- Различай «не посчитано» (`value=None`) и «не прошло порог» (`passed=False`).
  Это разные исходы: первый ведёт к отказу системы, второй — к отрицательному ответу.

## Стиль

- Python 3.11+, аннотации типов обязательны, Pydantic v2 на всех границах.
- Комментарии объясняют «почему», а не «что».
- Длинные функции лучше, чем преждевременные абстракции: у нас 40 часов, а не полгода.
