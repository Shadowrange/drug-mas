## Сценарий 1 — Оптимизация лида (`lead_optimization`)

* **Запрос:** `Модифицируй структуру иматиниба так, чтобы повысить растворимость и сохранить сродство к BCR-ABL1, отфильтруй токсичные аналоги`
* **Эталонные файлы:** [`examples/scenario1.json`](../examples/scenario1.json) · [`examples/scenario1.png`](../examples/scenario1.png)

### Выполненные шаги
1. `pubchem_smiles("imatinib")` — извлечена структура иматиниба (`PubChem CID 5291`, SMILES: `Cc1ccc(NC(=O)c2ccc(CN3CCN(C)CC3)cc2)cc1Nc1nccc(-c2cccnc2)n1`, исходные свойства: `LogP = 4.59`, `LogS = -6.09 log mol/L`).
2. `pdb_structure("1IEP", ligand_resname="STI")` — загружена кристаллическая структура киназного домена BCR-ABL1 (разрешение `2.1 Å`), по координатам ко-кристаллизованного иматиниба (`STI`) вычислен геометрический центр кармана связывания `(15.614, 53.38, 15.455)`.
3. `generate.mutate` — алгоритмом STONED-SELFIES с фильтром химической состоятельности `chemically_sane` (`Tanimoto >= 0.40` к родителю) получено 7 валидных структурных аналогов.
4. `chem.run_all_filters` + `admet.profile` + `dock` — рассчитаны дескрипторы RDKit, фильтры Липински, PAINS и `SA_Score <= 6.0`, растворимость `LogS` по модели ESOL (Delaney 2004) и структурные предупреждения `Brenk_Alerts`. Для гибких молекул без дерева торсий Meeko/Vina жёсткий докинг с `TORSDOF 0` заблокирован (`dG: не посчитано`).

## Сценарий 3 — Честный отказ при недостатке данных (`insufficient_data`)

* **Запрос:** `Предложи ингибиторы для малоизученной мишени с малым числом активностей в ChEMBL`
* **Эталонные файлы:** [`examples/scenario3.json`](../examples/scenario3.json) · [`examples/scenario3.png`](../examples/scenario3.png)

### Выполненные шаги
1. `supervisor` — фильтр `_looks_like_target` отсекает общие русские слова и предлоги («с», «малым», «мишени»), не допуская ложного поиска по стоп-словам.
2. `data_agent` — фиксирует отсутствие подтверждённого идентификатора мишени и экспериментальных записей (`n_activities = 0`, `has_structure = False`).
3. `verifier.check_data_sufficiency` + `route_sufficiency` — формирует список недостающих данных `missing` и перенаправляет граф напрямую в `reporter` в обход `generator` и `evaluator` (`0` вызовов генератора).
4. `reporter` — собирает валидированный `ScenarioResult(status="insufficient_data", candidates=[])` и проверяет текст интерпретации кодовым постфильтром `_postfilter_insufficient_data_smiles`.

### Фактический результат (`status="insufficient_data"`, `candidates=[]`)

* **Предложенные молекулы:** `0` (`candidates = []`).
* **Структурированный список дефицита данных (`missing`):**
  1. **данные о биологической активности по мишени**: найдено `0 записей в ChEMBL`, требуется `не менее 100 записей одного типа (IC50 или Ki)`, разблокировало бы: `обучение QSAR-модели и предсказание активности кандидатов`.
  2. **экспериментальная 3D-структура мишени**: найдено `в PDB подходящей записи не найдено`, требуется `структура с разрешением лучше 3.0 Å, желательно с ко-кристаллизованным лигандом`, разблокировало бы: `молекулярный докинг и расчёт энергии связывания`.
* **Итоговое резюме (`summary`):**
  > «Молекулы-кандидаты системой не предлагаются, поскольку верификатор зафиксировал недостаточность входных экспериментальных данных и заблокировал запуск генератора структур. По категории «данные о биологической активности по мишени» обнаружено 0 (БД) записей в ChEMBL, тогда как для корректного моделирования требуется не менее 100 (расчёт) записей одного типа (IC50 или Ki), что разблокировало бы обучение QSAR-модели и предсказание активности кандидатов. По категории «экспериментальная пространственная структура мишени» в базе PDB подходящей записи не найдено, тогда как требуется структура с разрешением лучше 3.0 Å (расчёт) с ко-кристаллизованным лигандом, что разблокировало бы молекулярный докинг и расчёт энергии связывания. В отсутствие подтверждённого идентификатора мишени в запросе опрос базы активностей завершился отказом без выдумывания промежуточных структур или числовых оценок. Без указанных экспериментальных данных система может выполнять только детерминированный расчёт физико-химических дескрипторов и проверку структурных фильтров для явно переданных пользователем молекул, без прогноза биологической активности и без молекулярного докинга.»
