## Сценарий 3 — отказ при недостатке данных ⭐
**Запрос.** Предложи ингибиторы для малоизученной мишени с малым числом активностей в ChEMBL *(также проверяется тест-запросом: «Предложи ингибиторы для мишени <без данных в ChEMBL>»)*.

**Действия.** `supervisor` отфильтровывает стоп-слова/предлоги (`_looks_like_target`) · `data_agent` проверяет наличие подтверждённого ChEMBL ID и структуры (`n_activities = 0`, `has_structure = False`) → `verifier.check_data_sufficiency` формирует список `missing` и через роутер `route_sufficiency` **блокирует ветку генерации (`0` вызовов `Generator` и `Evaluator`)** → `reporter` формирует объяснённый отказ с постфильтром SMILES.

**Ожидаемый ответ.** Молекул НЕТ. Система перечисляет: сколько записей нашла и где, сколько нужно, что это разблокировало бы, что может сделать без этих данных.

**Фактический результат** ([`examples/scenario3.json`](../examples/scenario3.json), [`examples/scenario3.png`](../examples/scenario3.png)).
Статус: `status="insufficient_data"`, **`candidates=[]` (ни одной молекулы не предложено и ни одного SMILES в `summary` нет)**.
Список недостающих данных (`missing`):
- **данные о биологической активности по мишени**: найдено `0 записей в ChEMBL`, требуется `не менее 100 записей одного типа (IC50 или Ki)`, разблокировало бы: `обучение QSAR-модели и предсказание активности кандидатов`.
- **экспериментальная 3D-структура мишени**: найдено `в PDB подходящей записи не найдено`, требуется `структура с разрешением лучше 3.0 Å, желательно с ко-кристаллизованным лигандом`, разблокировало бы: `молекулярный докинг и расчёт энергии связывания`.
- **Текст интерпретации (`summary`):** *«Данных по запрошенной мишени недостаточно, поэтому молекулы-кандидаты системой не предлагаются. Отсутствует категория «данные о биологической активности по мишени»: обнаружено 0 записей в ChEMBL, требуется не менее 100 записей одного типа (IC50 или Ki), что разблокировало бы обучение QSAR-модели и предсказание активности кандидатов. Отсутствует категория «экспериментальная 3D-структура мишени»: обнаружено в PDB подходящей записи не найдено, требуется структура с разрешением лучше 3.0 Å, желательно с ко-кристаллизованным лигандом, что разблокировало бы молекулярный докинг и расчёт энергии связывания. Без указанных экспериментальных данных система может выполнять только детерминированный расчёт физико-химических дескрипторов и проверку структурных фильтров для уже известных структур, без предсказания биологической активности и без молекулярного докинга.»*

> Фраза для защиты: «Остальные системы в этой ситуации сгенерируют десять красивых молекул с выдуманными цифрами активности. Наша отказывается — и это и есть применимость в реальной разработке».
