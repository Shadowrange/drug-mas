# Сценарии

Формат защиты: запрос → ожидаемый ответ → действия системы → **фактический результат**.
Последнюю колонку заполняет Р-D по итогам прогонов в четверг, из `examples/`.

## Сценарий 1 — оптимизация существующего соединения
**Запрос.** Модифицируй структуру иматиниба так, чтобы повысить растворимость и сохранить сродство к BCR-ABL1, отфильтруй токсичные аналоги.
**Действия.** PubChem CID 5291 → SMILES · PDB 1IEP → рецептор и центр бокса по ко-кристаллизованному лиганду · CReM → 50 аналогов · RDKit-фильтры · ADMET · докинг топ-5 · PLIP.
**Ожидаемый ответ.** Таблица топ-5 с LogP, QED, SA, ΔG, 3D-поза, у каждого числа бейдж источника.
**Фактический результат.** _заполнить_

## Сценарий 2 — поиск и ранжирование под мишень
**Запрос.** Найди известные ингибиторы EGFR (UniProt P00533), обучи модель активности и предложи 3 новых кандидата.
**Действия.** UniProt P00533 · ChEMBL CHEMBL203 → активности · ECFP4 → CatBoost · генерация вокруг лучших скаффолдов · скоринг.
**Ожидаемый ответ.** Сводка по мишени, **метрики модели рядом с каждым предсказанием**, 3 кандидата с оценкой синтетической доступности.
**Фактический результат.** _заполнить_

## Сценарий 3 — отказ при недостатке данных ⭐
**Запрос.** Предложи ингибиторы для мишени <без данных в ChEMBL>.
**Действия.** Data Agent ищет активности, находит единицы записей → `verifier.check_data_sufficiency` блокирует ветку генерации.
**Ожидаемый ответ.** Молекул НЕТ. Система перечисляет: сколько записей нашла и где, сколько нужно, что это разблокировало бы, что может сделать без этих данных.
**Фактический результат.** _заполнить_

> Фраза для защиты: «Остальные системы в этой ситуации сгенерируют десять красивых молекул с выдуманными цифрами активности. Наша отказывается — и это и есть применимость в реальной разработке».
